# 湿地鸟类民俗节专题（沧澜湾）

访客网页可切换 **鸟类 / 民俗仪式 / 亲子活动**；管理端维护 **观测点、限制区、公告与空间有效区间**、物种订正、活动改期、观测记录与图片元数据。

## 运行

```bash
npm install        # 仅依赖 express（纯 JS，无原生模块）
npm start          # http://localhost:3000 ，管理端 /admin.html（默认令牌 dev-admin-token）
npm test           # 11 项验收测试（固定时钟 2026-10-07）
```

令牌用环境变量覆盖：`FESTIVAL_ADMIN_TOKEN=xxxx npm start`。

## 可见性方案：固定公开点 vs 限制区实时过滤

**采用“限制区实时几何过滤”，策展白名单（fixed_public）不豁免。**
点是否可公开展示，由服务端在每次请求时用 **实际几何关系（点在多边形内，含边界从严）× 当前生效限制区** 计算：

- 落在任何生效限制区内 → 列表、地图、打印卡、活动关联、记录/图片关联全部隐藏；
- **不使用行政名称匹配**：同名同区域但几何在区外的点照常展示，区内同名点照常隐藏（测试 2）；
- 种子数据中 s3「旧瞭望台」是旧的固定公开点，几何位于核心区，因此始终隐藏；
- 限制区带空间有效区间 `[valid_from, valid_to)`，未来/过期不遮挡。

### 边界变化后的全渠道失效

- 限制区任意写操作（含“晚到”的新规，甚至生效时间回填到过去）→ `zone_epoch + 1`；
  其他内容写操作 → `content_epoch + 1`；版本串 `z{zone_epoch}-c{content_epoch}`。
- 地图、文本、打印卡由**同一个公开包**构建，天然同版；打印卡带版本号，入口版本不一致即声明作废，点隐藏返回 `410 Gone`。
- 所有响应 `Cache-Control: no-store` + `X-Content-Version`；页面轮询 `/api/version`，版本变化即刷新。
- Service Worker 缓存以版本命名：边界版本一变，旧缓存（**离线旧计划**）整体删除；
  离线时不渲染地图坐标，打印卡在无法联网校验版本时拒绝输出。

## 敏感坐标保护

观测记录位置与可公开位置分离存储：记录存 `exact_lat/exact_lng`，仅管理端包与**管理端 CSV**出现。
公开包按 `share_coarse` 决定：给约 1km 网格（2 位小数）或不给坐标；
图片 EXIF 的 `gps_lat/gps_lng` 在公开包和 `/api/export/images.json` 中一律剥离（或仅网格）；
公开 CSV 没有精坐标列。站点被隐藏时，其记录、图片、活动上的站点身份一并移除，杜绝反查。

## “来源材料”免责

鸟讯与潮汐只是来源材料：公开包内联 `disclaimers`（见鸟讯/潮汐/进入条款），
**不保证一定见鸟，也不构成进入许可**。潮汐条目标记 `cross_day` 跨日窗口；鸟讯不提供可定位方位。

## 验收场景（test/acceptance.test.js）

1. 几何优先：固定公开点 s3 在核心区 → 列表/地图/打印卡一致隐藏，打印卡 410
2. 行政名称不参与判定（同名点一隐一显由几何决定）
3. 敏感栖息地：列表/图片元数据/公开导出不泄精坐标；管理端导出保留；无令牌 401
4. 切语言不能绕过点位隐藏；缺翻译回退并标记“待补信息”
5. 同名物种订正：重复录入 sp5 合并入 sp3（记录 r3、图片标签迁移）；凤头/灰头麦鸡同名不同种打消歧标记保留
6. 一图多鸟：img1 多物种标签保留，EXIF 坐标仍剥离
7. 潮汐跨日（23:50 高 / 次日 00:40 低，窗口跨午夜）+ 免责声明
8. 活动改期：公开只呈现新日期，旧日期仅管理端审计历史
9. 限制区新规晚到：s4 即时全渠道消失、`zone_epoch+1`、打印卡 410、撤销后恢复
10. 空间有效区间：未开始的区不遮挡；过期公告退出公开包
11. 地图/文本/打印卡同版，版本串与响应头一致

## 目录

- `server/`：`server.js`（API/静态）、`db.js`（JSON 服务数据库）、`geo.js`（点在多边形/有效区间/降精度）、
  `pack.js`（公开/管理端内容包与脱敏）、`seed.js`（演示数据）

  `admin.html`/`admin.js`（管理端）、`sw.js`（版本化离线缓存）、`i18n.js`（缺翻译处理）
